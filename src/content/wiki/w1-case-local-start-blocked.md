## 오늘의 결과부터

블로그 메뉴를 만들고 내 컴퓨터에서 열어보려 했지만, 앱 제작과 실행까지 가지 못했다. 남은 것은 학습허브, 만들 범위를 정한 PRD, 입력부터 결과까지 설명한 개념페이지다. 실행 주소는 없다.

이 글은 완성된 앱의 성공 사례가 아니다. AI와 제작을 시작하다 멈췄을 때, 어디까지 했고 무엇이 남았는지 구분한 기록이다. 처음 만드는 사람이나 라이브 시연을 준비하는 사람에게 참고가 될 수 있다.

## 큰 목표를 블로그 메뉴 하나로 좁혔다

처음에는 개발자 AI 에이전트를 만들고 싶었다. 하지만 시연 중에 구현하기에는 범위가 컸다. 대화에서 이렇게 방향을 바꿨다.

“그냥 사이트에 블로그 메뉴 추가하는 걸로 하자 지금 시연중이라 에이젼트 만들기 어려워”

첫 기능은 블로그 메뉴를 누르면 기존 글 목록이 나오고, 글을 고르면 본문이 열리는 것으로 정했다. 연재 순서 변경이나 새 글 작성은 뒤로 미뤘다.

학습허브는 기록을 담는 곳으로 두고, 실제 앱은 나란한 별도 폴더에서 만들기로 했다. 앱 폴더에 PRD를 저장하고 허브에는 개념 설명만 남겼다. 이 단계까지는 실제 파일이 생겼다.

## 첫 번째 막힘: 실행 전에 메모리가 부족했다

다음으로 이렇게 요청했다.

“학습허브를 로컬로 띄워줘”

확인 결과, 허브에 필요한 패키지가 아직 설치되지 않았다. 당시 컴퓨터의 메모리 여유는 약 2.3GB, 사용률은 약 85%였다.

이 작업공간에는 메모리 사용률이 75% 이상이거나 여유가 4GB 이하이면 새 무거운 작업을 시작하지 않는 규칙이 있었다. 그 규칙에 따라 설치와 서버 실행을 보류했다. 모든 컴퓨터에 적용되는 실행 불가 기준이라는 뜻은 아니다.

재시도 때는 여유가 약 4.27GB, 사용률이 약 73%로 바뀌었다. 무엇 때문에 개선됐는지는 기록에서 확인되지 않는다. 자원 조건은 나아졌지만, 그것만으로 앱이 실행된 것은 아니었다.

## 두 번째 막힘: 제작할 작업 폴더가 달랐다

앱 제작을 요청한 대화는 여전히 전체 작업공간을 열고 있었다. 앞서 정한 진행 조건은 앱 폴더를 Codex에서 별도 프로젝트로 여는 것이었다.

AI는 이 대화의 프로젝트를 직접 전환할 수 없다고 안내하고, 열어야 할 앱 폴더와 이어갈 문장을 남겼다. 이 조건 때문에 구현을 시작하지 않았다. 다른 경로의 파일을 전혀 읽거나 쓸 수 없다는 오류가 발생한 것은 아니다.

허브 안에 앱을 대신 만들지는 않았다. 현재 기록에는 앱 폴더를 새 프로젝트로 연 결과나 그 뒤의 구현 기록이 없다. 따라서 이 막힘은 아직 해결됐다고 적을 수 없다.

## 파일이 생긴 것과 작동한 것을 나눴다

| 구분 | 기록으로 확인한 상태 |
|---|---|
| 학습허브 템플릿 | 다운로드한 파일 존재 확인 |
| 첫 제작 범위 | 블로그 메뉴 → 기존 글 목록 → 본문 열기로 확정 |
| PRD·개념페이지 | 파일 저장 확인 |
| 앱 코드 | 아직 작성하지 않음 |
| 의존성 설치·서버 실행 | 아직 하지 않음 |
| 블로그 클릭 동작 | 미검증 |
| 새 대화에서 절차 재사용 | 미검증 |
| 외부 공개·배포 | 하지 않음 |

시작할 때는 실행되는 화면을 기대했다. 끝날 때 확보한 것은 제작 범위와 재개 위치였다. 기대한 결과에 도달하지 못한 부분까지 기록해 두면 다음 대화가 완료된 것으로 오해하고 넘어가는 일을 줄일 수 있다.

## 다음에 그대로 쓸 확인 방법

다음 제작을 시작할 때는 아래 네 가지를 먼저 확인할 수 있다. 오늘 실제 동작 검사를 마쳤다는 뜻이 아니라, 오늘의 막힘에서 정리한 재개용 확인표다.

1. 지금 열린 프로젝트가 실제 앱 폴더인지 확인한다.
2. 그 폴더의 정본 PRD와 기존 코드를 읽는다.
3. 설치·실행 전에 컴퓨터 자원이 작업공간 규칙을 만족하는지 확인한다.
4. 결과를 보고할 때 저장한 파일, 실제 실행, 직접 눌러본 동작을 따로 적는다. 실행하지 않았다면 주소를 만들거나 성공했다고 쓰지 않는다.

다음에 사용할 문장:

docs/prd.md를 읽고 블로그 메뉴 → 기존 글 목록 → 본문 열기를 구현해서 로컬로 실행해줘.

이 문장은 다음 실행을 위한 안내이며, 실행 완료 증거가 아니다. 실제로 메뉴와 글을 열어보는 일은 다음 작업에 남아 있다.

## 기록의 범위

이 글은 오늘 대화와 확인한 학습일지에 근거한다. 별도로 답하지 않은 감정이나 다른 대화에서의 성과는 넣지 않았다. 개인 정보와 원문 인터뷰 전체도 옮기지 않았다.

현재 비공개 초안이다. 허브의 프로젝트 카드는 아직 템플릿 예시여서 실제 프로젝트로 연결하지 않았다.
