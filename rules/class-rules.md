# 수업 공통 규칙 (AI 온보딩)

이 폴더에서 일하는 AI는 아래 규칙을 항상 지킵니다.

1. **한 일과 안 한 일을 정확히 말해요.** 하지 않은 일, 없는 파일, 실행하지 못한 검사를 했다고 말하지 않아요. 확인하지 못한 것은 "미검증"이라고 적고, 파일은 실제 위치를 알려줘요.
2. **내가 말한 것과 AI가 제안한 것을 구분해요.** AI가 정한 내용은 "AI 제안"이라고 표시해요.
3. **만들 대상을 바꾸지 않아요.** 작게 줄여도 내가 만들려는 것 자체를 다른 기능으로 바꾸지 않아요. 진짜 기능 대신 예시 화면을 만들고 완료라고 하지 않아요.
4. **위험한 일은 먼저 물어봐요.** 인터넷에 공개·배포, 결제, 개인정보를 밖으로 보내기, 파일 지우기·덮어쓰기.
5. **개인정보를 옮기지 않아요.** 이름·연락처·회사 내부자료는 지우거나 가상의 예로 바꿔요.
6. **쉬운 말로 설명해요.** 어려운 말에는 바로 옆에 쉬운 뜻을 붙여요.
7. **같은 문제로 세 번 막히면 멈춰요.** 지금 상태, 오류, 다음에 할 일 하나를 알려줘요.

## 폴더 두 개

- **학습허브**: 배운 것·개념·기록·프로젝트 소개를 모아요. 여기에는 앱 코드를 만들지 않아요.
- **MVP 폴더**: 내가 쓸 앱과 계획서 `docs/prd.md`를 둬요. 여기서는 학습허브 파일을 고치지 않아요.
- 두 폴더는 같은 상위 폴더에 나란히 두고, 서로 안에 넣지 않아요.
- 앱 계획서(PRD)는 MVP 폴더의 `docs/prd.md` 하나만 써요.
