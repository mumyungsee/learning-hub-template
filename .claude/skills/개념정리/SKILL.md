# 모르는 것 → 개념 시나리오 페이지

모르는 개념을 사전처럼 외우게 하지 말고, 주인이 실제로 무언가를 해나가는 장면 속에서 이해하게 합니다. PRD를 만든 뒤뿐 아니라 계획·제작·검수 중 궁금한 것이 쌓일 때마다 다시 사용하는 공부 방법입니다.

## 1단계 · 무엇을 이해할지 고르기

최근 대화와 주인이 가리킨 PRD·계획·오류를 읽고, 지금 이해해야 할 중심 흐름 하나를 고릅니다.

- 어려운 말을 전부 담지 말고 현재 작업을 이해하는 데 필요한 것만 고릅니다.
- 같은 주제의 기존 개념 페이지가 있으면 이어서 고치고, 주제가 다르면 새 페이지를 만듭니다.
- 주인이 실제로 말하거나 겪지 않은 사실은 지어내지 않습니다. 학습을 위한 가상 장면이면 가상 예시라고 밝힙니다.

## 2단계 · 장면으로 설명하기

가상의 초보자 또는 주인이 실제 작업을 해나가는 짧은 시나리오로 씁니다.

- 큰 흐름을 실제 작업 순서대로 놓고, 한 장면에는 행동 하나만 둡니다.
- 초보자는 정답을 아는 긴 프롬프트를 쓰지 않습니다. 모르는 것을 짧게 묻고, AI가 용어와 다음 행동을 설명합니다.
- 각 장면은 **질문 또는 막힘 → AI의 쉬운 설명 → 행동이나 확인 결과**가 보이게 합니다.
- 한 장면에 새 개념은 최대 2개만 넣습니다.
- 최소 한 장면에는 “아직 어려워”, 화면·오류 보여주기, 다시 확인하기처럼 모름이나 막힘을 해결하는 모습을 넣습니다.
- 대화 뒤 설명은 한 줄만 둡니다. 같은 내용을 대화와 설명문에서 반복하지 않습니다.

## 3단계 · 어려운 말에 툴팁 달기

본문에서 비개발자가 모를 말을 찾고 기존 툴팁 모듈을 사용합니다.

- 툴팁 정본은 `src/scripts/glossary-tooltip.ts`입니다. 새 모듈이나 별도 툴팁 코드를 만들지 않습니다.
- 이미 있는 용어는 기존 설명을 재사용합니다.
- 사전에 없는 말만 `glossaryTerms` 배열에 추가합니다.
- 설명은 그 용어보다 쉬운 일상어 한 문장으로 씁니다. 설명 안에 또 어려운 말을 넣지 않습니다.
- 파일명이나 용어를 `code`로 감싸면 툴팁이 뜨지 않으므로, 툴팁이 필요한 자리에서는 일반 글자로 씁니다.

## 4단계 · 개념 요약표와 저장

페이지 끝에 시나리오에서 다룬 말을 한 번에 복습하는 표를 넣습니다.

| 장면 | 개념 | 쉬운 뜻 |
|---|---|---|
| 장면 번호 | 그 장면에서 처음 나온 말 | 한 문장 설명 |

`src/content/wiki/`에 저장합니다.

- 프론트매터: `title`, `date`, `종류: 개념`, `주차`, `공개: true`
- 파일명: 영문·숫자·하이픈 조합
- 같은 주제를 갱신할 때는 기존 파일에 장면이나 설명을 추가하고 중복은 정리합니다.

> 완료 기준 — 초보자가 작업 흐름을 따라가며 개념을 이해할 수 있고, 어려운 말에 쉬운 툴팁이 뜨며, 위키에 개념 시나리오 페이지가 저장됨

## 짝 · 사례따라하기
